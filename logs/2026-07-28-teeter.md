## Game Details
- **Name / repo:** Teeter / ben-gy/teeter
- **Genre:** arcade
- **Core loop:** tilt the phone → a marble rolls under momentum → steer it through a maze
  to the exit; score is time.
- **Multiplayer:** live P2P versus 2–6, a parallel same-seed race (no ball state on the
  wire; host transfer = pure display concern).
- **Stack / render:** vanilla-ts / canvas
- **Engine modules used:** net, rematch, turn, lobby, qr, rng, joystick, sound, storage,
  mobile (+ mobile.css), identity, feedback (hosted)

## Sensor (principle #23)
- **Primary input:** gyroscope (`DeviceOrientationEvent`), pure `tiltFromOrientation`
  derivation with per-round neutral calibration + screen-orientation rotation.
- **Fallback (built first):** the engine's floating joystick on touch, arrow keys/WASD on
  desktop — same physics, honest "No tilt sensor — drag anywhere to steer" announce.
- **Privacy:** orientation angles only — no stream, no camera/mic, nothing to record or
  stop at teardown. Disclosed at the About/permission point.
- **Testability:** pure derivation unit-tested; a synthetic-feed browser hook proved the
  injected-sample → physics wiring end-to-end (a real-device tilt check is NOT possible
  in this pipeline — stated plainly).

## Juice
