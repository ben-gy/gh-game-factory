## Game Details
- **Name / repo:** Wordloom / ben-gy/wordloom
- **Genre:** word
- **Core loop:** letters arrive one at a time → drop each into an empty square → when
  the grid is full, every row and column scores its best contiguous 3+ word; longer
  words worth much more; you can't move a placed letter.
- **Multiplayer:** live P2P versus 2–6 as a PARALLEL SAME-SEED RACE (each peer weaves
  its own grid from the identical seeded letter stream; only a tiny status gossip
  {score,placed,done} + the final grid on finish crosses the wire; host transfer is a
  pure display concern). Plus solo-first, a UTC daily, and async seed-share.
- **Stack / render:** vanilla-ts / DOM
- **Engine modules used:** net, rematch, turn, lobby (+qr), rng, sound, storage, mobile,
  identity

## Modes (real spread — the RULE changes, principle #14)
- **Weave** — 5×5, blind one-at-a-time, rows + columns (10 lines).
- **Sluice** — 5×5, see a queue of the next 3 and place ANY of them (which letter AND
  which cell); refills from the stream. Planning over luck.
- **Deluge** — 6×6, blind, rows + columns AND both main diagonals (14 lines); the
  centre cells are triple-weighted.

## Juice
Procedural SFX on placement (pitch rises with tile value), a `win` sweep at grid-full,
a settle/drop tween on the placed tile, a subtle score-gain pulse, haptics, live
word-highlighting (amber weft underline for rows, teal warp side-bar for columns,
violet ring for diagonals), a 3-2-1-Go count-in. Respects prefers-reduced-motion.

## Dictionary
Curated common-word list (`scripts/gen-dictionary.mjs`) from SCOWL frequency bands via
`wordlist-english`, length-scaled leniency (len3 ≤ band 35 … len6 ≤ 60). Only lengths
3–6 (the longest scoring line is 6). 15,839 words, ~38KB gz, inlined via `?raw`.
Regression test: known junk (NOM/GOS/QAT/…) rejected, common inflections + real long
words (CATS/PLAYED/ABSEIL/QUARTZ) accepted.
