## Game Details
- **Name / repo:** Glint / ben-gy/glint
- **Genre:** party (fast visual-search)
- **Core loop:** two cards always share exactly one symbol; find it, tap it, a new card deals; chain clean taps for a combo.
- **Multiplayer:** live P2P (2–6), parallel same-seed race — no game state on the wire, host transfer a pure display concern.
- **Stack / render:** vanilla-ts / canvas 2D.
- **Engine modules used:** net, rematch, turn, lobby (+ qr), rng, sound, storage, mobile, identity.

## Juice
Particle bursts on a correct tap (accent colour) and a red burst + screen shake on a miss,
combo pops with milestone flashes, correct/wrong vignette flash, deal-in pop, procedural
audio (coin pitched by combo, lose thud, count-in beats), haptics, 3-2-1-GO count-in.

## Errors & Resolutions
- **De-seam spread bug (deck.ts):** `block.slice(1).concat(block[0])` spread the card array's
  numbers into the sequence instead of appending the card, leaving numeric "holes" that crashed
  `sharedSymbol` ("b is not iterable") on seeds where a shuffle block boundary collided. Invisible
  to the happy-path game test (seed 999 didn't collide); surfaced immediately by the balance sim's
  many-seed sweep. Fixed with `[...block.slice(1), block[0]]`; mutation-verified (both sweeps red on
  revert). This is exactly the "build the sim first and let it referee" lesson (principle #18).
- **Empty finite sequence:** the first sim run crashed because finite (Sprint) mode passed
  `minLen: 0` to buildSequence, so the while-loop never ran and the deck was empty. Fixed to pass
  `planeSize(order)`.
- **Symbol layout crowding:** the first in-browser pass showed the centre glyph slightly crowding a
  ring glyph on dense cards; extracted the layout into a pure `symbolLayout()` with wider spacing
  and pinned the non-overlap invariant in layout.test (mutation-verified).
