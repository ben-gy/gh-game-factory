## Game Details
- **Name / repo:** Skein / ben-gy/skein
- **Genre:** puzzle
- **Core loop:** drag beads so no threads cross; every web is planar by construction so a solution
  always exists; fewer moves is a better solve.
- **Multiplayer:** live P2P, 2–6, non-hostile parallel same-seed race (no game state on the wire).
- **Stack / render:** vanilla-ts / canvas
- **Engine modules used:** net, rematch, turn, lobby, qr, rng, sound, storage, identity, mobile

## The generator (the crux)
Planar by construction: lay beads out in a spread (the SOLUTION positions), build a Euclidean
minimum spanning tree (its edges provably never cross) plus extra edges added only when they cross
nothing already placed and don't run through a third bead, then scramble the beads to make the
tangle. `countCrossings(solution) === 0` is pinned across 150 seeds × modes — the objective is
completable by construction, and the player is never stuck. Totality guaranteed by a random-order
ring fallback, so a daily seed can never hang.

## Juice
Coral crossed threads with a pulsing ✕ at each cut, cyan clean threads, amber beads; grab-lift +
halo on a grabbed bead; clear-spark when a drop removes crossings; a green solve pulse + burst; a
budget-death shake + red flash. Procedural SFX (grab/clear/solve/next/budget). prefers-reduced-
motion aware. Particle pool hard-capped (a backgrounded tab or a very fast solver can never grow it
unbounded — found and fixed during the local browser pass).

## Errors & Resolutions
- Unbounded particle growth: firing many solves quickly (or a backgrounded tab whose rAF is
  throttled so particles never age) could pile up thousands of particles. Fixed with a hard cap on
  the particle pool (180) and a trimmed per-solve burst. Not a real-play bug, but good hygiene.
- Three test-authoring bugs found during the first suite run (a mislabeled geom fixture, a
  degenerate Snarl placement that collapsed the web to zero-length edges, and an adjacency-teeth
  mutation that is genuinely inert for straight segments) — all fixed; the game logic was correct.
