## Idea Source
IDEAS.md, first entry of the board-game initiative queue (removed on take):

> **Skyhold** (Santorini-shaped) — on a small grid, each turn MOVE one of your two builders up to one
> height then BUILD a block (or dome) on an adjacent square; first to step a builder onto a
> third-level tower wins, and drafted "power" tiles (an extra build, a push, a swap) are the three
> modes. vs 2 (3-4 variant), lockstep + minimax bot; procedural isometric towers.

The mechanic is reimplemented; the identity is original throughout (name, art, copy, tile names).
The source game is never referenced in anything shipped.

## Game Details
- **Name / repo:** Skyhold / ben-gy/skyhold
- **Genre:** board
- **Core loop:** move one builder one square, then raise one block beside it; win by stepping from a
  second storey onto a third, or by leaving your rival no legal turn. Every block is a staircase for
  you and a wall for them, so the game is won on the fork.
- **Multiplayer:** live P2P, **deterministic lockstep**, exactly 2 seated players (+ spectators)
- **Stack / render:** vanilla-ts / DOM CSS-grid board, canvas for particles + the isometric results
  portrait
- **Engine modules used:** net, rematch, turn, lobby (+ qr), rng, sound, storage, mobile, identity

## Input question (principle #23)
Asked and answered on purpose: **touch**. A perfect-information abstract is a deliberation game — the
input must be precise and re-considerable, and tilting or shouting at a chess-like board is a novelty
tax on the one shape where precision *is* the product. The fleet's sensor quota is well served by the
last four runs (warble = voice, brim = accelerometer, waft = camera, glint = perception); the queue's
board-game initiative is explicitly asking for the tap-first game this run builds.

## Scope decisions
- **2 players only.** The idea mentions a 3–4 variant; a 7×7 board fails the 44px arithmetic at 320px
  and a 3-player elimination game needs a walkover model the 2P contract does not have. Dropped, and
  said so rather than shipping it half-done.
- **No subtractive power.** Every legal turn therefore raises total height by ≥1, and total height is
  bounded by 4×cells — which replaces a repetition rule, a draw rule and a stalemate detector with a
  one-line proof the mechanism audit asserts at zero tolerance.
- **Seeded 180°-symmetric opening terrain**, so a random board cannot favour a seat, the deterministic
  abstract gets real opening variety, and the very first frame teaches the height encoding.

## Juice
Piece hop transposed by storeys climbed (a climb *sounds* like a climb), block-placed pitch rising per
level with a board shake on the third, dome cap with a dust puff, a gold winning slab with a particle
burst and screen shake, a salmon "sealed in" flush, and a thud on an illegal tap that consumes
nothing. All procedural Web Audio. `prefers-reduced-motion` swaps every transform for a crossfade and
never creates the particle canvas at all.

The shipped opening constant came out of the sweep, not out of taste:

| config | first-mover |
|---|---|
| ABAB, first placer also moves first | **60.0%** CI[51,68] |
| **ABAB, first placer moves SECOND (shipped)** | **48.3%** CI[40,57] |
| ABBA, moves first | 55.0% |

A counter-config assertion now fails if anyone flips it back.

**Charter's tiles were measurably broken and the sim found it.** With the draft bypassed (both seats
assigned at random, so a preference order cannot hide a dominant tile): Gale **74.4%**, Warden
**41.2%**. Gale's real verb was "displace a rival off the high ground and take it" — tempo, position
and an ascent for one charge. Fixed with a **no-climb shove** plus a per-tile charge budget
(Gale 2, Warden 5, rest 3). All five tiles now sit **45.4–52.9%**. Separately, the bot's draft
preference had been picking the *weakest* tile first; it is now ordered by the measured rates.

### Mechanism audit (principle #21)
`tests/mechanism.test.ts` replays every sim game through an implementation written from the rule text
— it never calls `genPlies` — and counts illegal plies, false wins, false smothers, builders inside
domes, overspent charges, height that failed to rise, and missed wins. All zero.

The metric had to be re-derived once: "a climb was available and they played something else" scored 2
violations, and the position turned out to be the search legitimately preferring a **smother** win.
The honest invariant is "a win was available and they played a move the game SURVIVED", which needs
no second move generator and has no grey zone. Positive controls are included — a random player
scores violations and a tampered log is rejected — so the audit cannot only ever return zero.

## Errors & Resolutions
Three defects the gates caught, each fixed and **mutation-verified** (revert → red → restore → green):

1. **Desktop board collapsed to a 10px horizontal strip.** `--board: min(100%, …)` sets width *and*
   height, and a percentage in the height resolves against an auto-sized grid row. Every phone check
   was perfect. The layout test could not see it because it evaluated what the CSS *meant* rather
   than what the browser does — so the fix is now a source-level invariant: `--board` may never
   contain a percentage.
2. **A landscape phone fell into the tablet media query** (812×375 is 720–999px *wide*), which won
   the cascade over the landscape rule and handed it a 115px board with 16.6px cells. The
   short-viewport rule is now last, and the layout test evaluates the real cascade rather than one
   rule in isolation.
3. **The survivor waited forever when the opponent's tab vanished.** Trystero never reported the peer
   as gone, so `onPeerLeave` never fired and the walkover never armed — with every unit test green,
   because they all *told* the Duel the peer had left. A peer that stops heartbeating for 20s is now
   treated as absent regardless of the transport (`tests/silence.test.ts`). Found alongside it: the
   round clock was fed a hard-coded 250ms per tick, so in a backgrounded tab every timer ran at a
   quarter speed and a 20s hold took 80 real seconds; it measures real elapsed time now.

Smaller fixes from looking at it: grid cells could not shrink below their intrinsic minimum (guarded);
the placement phase ringed all 25 squares as "legal", hiding the terrain; Mason's second-block targets
drew the move marker instead of the build marker; the draft offered four bare tile names with no rules
text on a phone; the post-hoc verdict counted both players' turns ("turn 21" in an 11-turn game) and
addressed the loser as "you" even when the loser was the bot; two peers with the same default handle
rendered an unreadable results screen; and `?room=` was not cleared on leaving a room.
